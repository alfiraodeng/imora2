IMORA Forecast API

Panduan integrasi forecast cuaca IMORA untuk aplikasi atau server lokal.

Versi 1.0 · 19 Oktober 2026 · Untuk integrasi teknis internal
Ringkasan: endpoint ini memberikan data forecast cuaca untuk titik operasional Indexim atau koordinat yang Anda tentukan. Endpoint dapat dipanggil dari aplikasi web lokal maupun backend karena CORS sudah diaktifkan.

1. Endpoint publik

GET Forecast seluruh titik operasional Indexim:

https://imora.indexim.id/api/v1/forecast

Tidak memerlukan login, API key, atau token. Respons berformat JSON.

2. Data yang tersedia

Setiap titik berisi forecast per jam untuk tiga hari secara default:

  • Suhu udara (temperature_2m)
  • Kelembapan relatif (relative_humidity_2m)
  • Curah hujan (precipitation) dan probabilitas hujan
  • Kode kondisi cuaca WMO (weather_code)
  • Kecepatan angin dan hembusan angin (wind_speed_10m, wind_gusts_10m)

Sumber data forecast: Open-Meteo. Zona waktu pada respons mengikuti titik forecast (untuk lokasi Indexim: Asia/Makassar / GMT+8).

3. Request dasar

cURL

curl https://imora.indexim.id/api/v1/forecast

JavaScript / browser atau Node.js

const response = await fetch('https://imora.indexim.id/api/v1/forecast');
if (!response.ok) throw new Error('Forecast tidak tersedia');

const payload = await response.json();
console.log(payload.results);

4. Forecast untuk koordinat sendiri

Kirim pasangan latitude dan longitude yang dipisahkan koma. Urutan latitude harus sama dengan longitude. Maksimum 50 titik per request.

https://imora.indexim.id/api/v1/forecast?latitude=1.043559,-6.200000&longitude=117.657709,106.800000&forecast_days=7
ParameterWajibKeterangan
latitudeUntuk titik sendiriLatitude, tunggal atau dipisahkan koma. Nilai -90 sampai 90.
longitudeUntuk titik sendiriLongitude, jumlahnya harus sama dengan latitude. Nilai -180 sampai 180.
forecast_daysTidak3 (default) atau 7.
 
const url = new URL('https://imora.indexim.id/api/v1/forecast');
url.searchParams.set('latitude', '1.043559');
url.searchParams.set('longitude', '117.657709');
url.searchParams.set('forecast_days', '7');

const { results } = await fetch(url).then((r) => r.json());
const hourly = results[0].forecast.hourly;
console.log(hourly.time, hourly.precipitation);

6. Cache dan pembaruan

  • Respons endpoint di-cache hingga 5 menit agar stabil dan tidak membebani provider forecast.
  • Untuk integrasi rutin, panggil endpoint maksimal satu kali per lima menit per titik/kelompok titik.
  • Simpan generated_at pada sistem lokal untuk mengetahui waktu data terakhir diterima.

7. Penanganan error

StatusArtiTindakan
200Forecast berhasil diambil.Proses results.
400Koordinat tidak valid atau jumlah latitude/longitude tidak sama.Periksa format parameter.
503Provider forecast sementara tidak tersedia.Simpan data terakhir dan coba ulang beberapa menit kemudian.

8. Batas keamanan data

Penting: endpoint forecast ini hanya memberikan data cuaca. Endpoint tidak mengembalikan akun pengguna, scenario, polygon monitoring, notifikasi, maupun riwayat operasional user.

Jika integrasi memerlukan ekspor data milik akun tertentu, gunakan endpoint privat /api/v1/data dengan access token Supabase dari akun tersebut. Token tidak boleh disimpan di source code, dikirim via chat, atau dibagikan ke pihak yang tidak berwenang.

9. Ringkasan untuk implementasi

  1. Panggil https://imora.indexim.id/api/v1/forecast untuk seluruh titik Indexim.
  2. Gunakan parameter koordinat bila membutuhkan titik sendiri.
  3. Gunakan data hourly untuk grafik, tabel, dan rule peringatan lokal.
  4. Simpan waktu respons dan lakukan refresh maksimal tiap lima menit.
